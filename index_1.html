Atelier SchemaCraft

Modifie les blocs d'un schéma Minecraft : .litematic, .schem, .schematic, .schema

Glisser pour tourner · molette pour zoomer · clic droit pour déplacer

Remplacer partout

Remplace un mot dans le nom de tous les blocs : oak → spruce change bûches, planches, escaliers, feuilles… d'un coup. Les orientations sont conservées.

→

Blocs

Survole un bloc pour le repérer dans l'aperçu, clique pour le changer.

Tout se passe dans ton navigateur : le fichier n'est envoyé nulle part. L'enregistrement télécharge le schéma modifié dans le même format. Un vieux .schematic d'avant 1.13 est enregistré en .schem, le format actuel de WorldEdit. Données des blocs : PrismarineJS/minecraft-data (MIT).
